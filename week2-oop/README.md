# 第 2 周：面向对象 + 异常处理

这周补 Python 最后一块：把「数据 + 操作数据的函数」打包成「类」。

## 学什么

1. 类（class）和对象（object）—— 图纸 vs 实物
2. `__init__` 初始化方法、`self`、属性
3. 方法（类里的函数）
4. 异常处理 try / except

## 练习

**小练习**：定义 `Point` 类，`__init__` 接收 `lon`（经度）和 `lat`（纬度），存成属性，然后创建两个点。

**本周小项目（进阶）**：把第 1 周的 CSV 统计工具用「面向对象」重构——封装成一个类，支持读 CSV 和 JSON 两种格式，文件不存在时用 try/except 友好报错（而不是直接崩）。

## 验收标准

- [ ] 能定义类、创建对象、访问属性
- [ ] 能说清 `self` 是什么
- [ ] 会用 try/except 处理「文件不存在」这种情况
