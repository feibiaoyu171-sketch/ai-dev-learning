# 第 1 周小项目：CSV 水深统计工具

## 任务

写一个命令行工具，读取 `points.csv`（里面是水深采样点数据），算出水深的最大值、最小值、平均值，打印出来。

`points.csv` 的列：`id, longitude, latitude, depth_m, date`。你只需要处理 `depth_m` 这一列。

## 怎么开始

1. 先把这一周要补的 Python 基础过一遍（变量、列表、字典、循环、函数、读写文件）。
2. 打开 `main.py`，按里面的 TODO 提示写。
3. 写完在终端跑：`python main.py`，看输出对不对。

## 验收标准（做到了才算过）
